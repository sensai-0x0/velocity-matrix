1. The Ambient Cortex: Voice Ingestion Contract
This contract defines the payload sent from the frontend when the hacker stops speaking. To keep the UI snappy, we send the transcribed text immediately, optionally deferring the raw audio blob for asynchronous LLM training or deeper analysis.

TypeScript
/**
 * UI -> Base44 Backend
 * Endpoint: base44.functions.invoke('process-voice-command')
 */
export interface VoiceIngestionPayload {
  hacker_id?: string;         // Optional client hint — Node 01 sets owner_id from JWT (never trust client)
  session_id: string;         // Ties the command to the current hackathon context
  timestamp_ms: number;       // For chronological ordering in the UI
  transcript: string;         // The raw text generated by the on-device STT
  context_tags?: string[];    // e.g., ["database", "auth", "routing"]
  urgency_flag?: boolean;     // Optional — Node 01 derives from stress keywords (B3)
}

export interface VoiceIngestionResponse {
  status: 'acknowledged' | 'rejected';
  blocker_id: string;         // The DB ID generated for this new task
  assigned_agent: string;     // Which AI node took the job (e.g., "llm_reasoning_core")
}
2. The Synthesis Grid: Real-Time State Stream
While the LLM processes the request, the UI must not freeze. The Base44 backend streams state updates via WebSockets. The UI uses these micro-payloads to control the visual intensity and rotation speed of the <SynthesisSpinner>.

TypeScript
/**
 * Base44 Backend -> UI (via WebSocket Subscription)
 * Entity: ActiveBlockers (Row updates)
 */
export interface SynthesisStateStream {
  blocker_id: string;
  status: 'parsing_intent' | 'querying_docs' | 'generating_logic' | 'verifying_syntax';
  completion_percentage: number; // Drives the visual fill of the Neuropunk UI elements
  current_focus: string;         // e.g., "Scanning Base44 Connectors..." (Displayed as micro-text)
  latency_ms: number;            // Displayed in the corner to emphasize system speed
}
3. The Resolution Feed: Artifact Delivery
When the AI finishes generating the solution, it writes to the GeneratedSolutions table. The Base44 real-time listener pushes this contract to the frontend, instantly rendering the <NeuralNode> code block.

TypeScript
/**
 * Base44 Backend -> UI (via WebSocket Subscription)
 * Entity: GeneratedSolutions (New Row Insert)
 */
export interface ResolutionArtifact {
  artifact_id: string;
  blocker_id: string;
  timestamp: string;
  
  // The primary visual payload
  solution_type: 'code_snippet' | 'architecture_diagram' | 'terminal_command';
  payload: {
    language: string;         // e.g., "typescript", "json"
    code: string;             // The raw code to be rendered with syntax highlighting
    file_path?: string;       // Target destination (e.g., "/src/components/Button.tsx")
  };
  
  // Minimalist context text to display above the code block
  neural_summary: string;     
  
  // Actions available to the hacker in the UI
  available_actions: Array<'deploy' | 'override' | 'discard'>;
}
4. Hacker Authority: Execution & Override Contract
If the hacker clicks [ Deploy ] or edits the code and clicks [ Override ], this contract is fired back to the Base44 connector manifest to execute the GitHub commit or Deno deployment.

TypeScript
/**
 * UI -> Base44 Backend
 * Endpoint: base44.functions.invoke('execute-resolution')
 */
export interface ExecutionPayload {
  artifact_id: string;
  action_taken: 'deploy' | 'override' | 'discard';
  
  // If the user modified the code in the glass panel, we send the diff/new code
  modified_code?: string;     
  
  // Execution instructions for Base44 Connectors (Document 06)
  target_connector: 'github_auto_commit' | 'cli_executor';
  commit_message?: string;    // Auto-generated unless overwritten by the user
}

export interface ExecutionResult {
  success: boolean;
  deployment_url?: string;
  error_trace?: string;       // Displayed in Bio-Crimson (#E11D48) if the commit fails
}
