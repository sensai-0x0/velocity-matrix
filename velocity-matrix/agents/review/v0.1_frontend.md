## 2. Completion Phases (ordered)

### Phase F0 — Foundation (SDK + tokens + client)

1. Add `src/api/base44Client.ts` exporting a singleton `base44` from `@base44/sdk` (Vite env / app id as Base44 docs require).
2. Add CSS tokens:
   ```css
   --crimson: #E11D48;
   --crimson-dim: #7f1d2e;
   ```
3. Keep `src/contracts/data_contracts.ts` as the only UI contract source (already canonical).
4. Optional path alias `@/` in `vite.config.ts` / `tsconfig` so Doc 04 imports resolve.

**Exit criteria:** App imports `base44` without runtime crash; crimson tokens usable in CSS.

---

### Phase F1 — Locked Cortex → Auth gate

Per `ui-plan` §3 and `auth_design.md`:

1. On mount: `base44.auth.me()` (or equivalent session probe).
2. **Locked:** dimmed wave, frozen amplitude, text affordance driven by enabled login methods (do not hard-code GitHub if only email is on).
3. On success: unlock → Ambient Cortex listening state.
4. If backend provision function exists, call it once after login (or rely on auto-hook).

**Exit criteria:** Unauthenticated users cannot invoke functions; authenticated users see live cortex.

---

### Phase F2 — View-state machine in `App` (or `CortexShell`)

Implement the single-surface machine from `ui-plan` §10 — **not** React Router pages:

```
Locked → Ambient → Synthesis → Resolution → (Ambient | Committed/Error)
         ↑______________ Cancel that ______________|
```

Suggested state:

```ts
type CortexView = "locked" | "ambient" | "synthesis" | "resolution" | "history";
```

Drive transitions **only** from:

| Event | Next view |
|-------|-----------|
| Auth ok | `ambient` |
| `process-voice-command` → `acknowledged` | `synthesis` |
| `GeneratedSolutions` subscribe `created` | `resolution` |
| Deploy/Override result | stay `resolution` + badge / crimson error |
| Voice `"Cancel that"` | `ambient` |
| Voice `"Show matrix history"` | `history` |

**Exit criteria:** Manual mock events can walk the full machine without blank screens.

---

### Phase F3 — Subscriptions (Doc 04)

1. Hook `useMatrixSubscriptions()`:
   - `ActiveBlockers.subscribe({ filter: { is_resolved: false }, onEvent })`
   - `GeneratedSolutions.subscribe({ onEvent })`
2. Upsert by `id`; prepend newest; return unsubscribe cleanups.
3. Map `ActiveBlockers` updates → `SynthesisStateStream` for the active `blocker_id`.
4. Map `GeneratedSolutions` created → `ResolutionArtifact` shape for `NeuralNode`.
5. `onError` → corner toast `MATRIX_DISCONNECT · reconnecting...` + resubscribe.

**Rules:** No raw WebSockets, no `setInterval` polling for entity data.

**Exit criteria:** Creating a blocker/solution in dashboard updates the UI without refresh.

---

### Phase F4 — Ambient Cortex (Node 01 UI)

1. Web Speech API (or documented fallback textarea for Safari / permission-denied).
2. On speech pause: build `VoiceIngestionPayload`:
   - `session_id` (stable per browser session)
   - `timestamp_ms`, `transcript`, `context_tags?`
   - `urgency_flag` if transcript matches urgent keywords
   - Do **not** send `owner_id`; send `hacker_id` only if contract still requires it — prefer aligning with backend to drop it
3. `base44.functions.invoke('process-voice-command', payload)`.
4. Drive `MatrixVoiceWave`:
   - `active` while listening
   - `amplitude` from analyser / Speech volume proxy
   - crimson spike when `urgency_flag`

**Exit criteria:** Spoken (or typed) pause → ack → Synthesis view.

---

### Phase F5 — Synthesis Grid (Node 02 UI)

Upgrade `SynthesisSpinner`:

| Prop | Source |
|------|--------|
| `synthesizing` | view === synthesis |
| `progress` | `completion_percentage` |
| `status` | stream `status` → stage labels (`>> PARSING_INTENT...` etc.) |
| `focus` | `current_focus` micro-text |
| `latencyMs` | corner counter |

Degraded UX (`ui-plan` §7): amber/dim spinner + `>> DEGRADED · RETRYING...` when row signals timeout/queue; crimson Failed Node when `is_resolved: false` and `parsed_issue` starts with `System Error`.

**Exit criteria:** Spinner intensity tracks live row updates.

---

### Phase F6 — Resolution Feed (Node 03 UI)

Upgrade `NeuralNode`:

1. Props: `summary`, `language`, `filePath`, `code`, `actions`, `committed`, `errorTrace`, `solutionType`.
2. Character type-reveal on new artifact; hover pauses for inline edit (glass panel).
3. Text actions from `available_actions`: `[ Deploy ]` `[ Override ]` `[ Discard ]`.
4. Invoke `execute-resolution` with `ExecutionPayload`; default `target_connector: 'github_auto_commit'`.
5. Success → show `deployment_url` + committed ✓; failure → `error_trace` in crimson.

**Exit criteria:** Full Deploy path from UI updates badge without console hacks.

---

### Phase F7 — Voice authority & polish

1. Continuous transcript listener for `"Cancel that"` / `"Show matrix history"` even during synthesis/resolution.
2. History layer: peripheral list of resolved blockers + prior solutions (low density; hidden by default).
3. Empty cortex: idle wave + `>> INGESTING_AUDIO...`.
4. Mobile: ensure first viewport remains one composition (brand + stage); actions remain text affordances.

**Exit criteria:** Cancel returns to Ambient; history toggles without route change.
